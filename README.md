Project Overview

The main idea is to see how hospitals across different states and categories perform in terms of both total charges and patient inflow.
The data is simulated to represent a country-wide inpatient dataset.

Features

Dashboard Page

KPIs showing Total Charges, Total Discharges, and Avg Charge per Discharge

Trend over time based on selected analysis type

Breakdown by hospital type

Geo map to show hospital distribution by state

Hospital Analysis

Stacked trend view by State → City → Category

Ability to drill down to see deeper details

Hospital Search

Table with hospital details and metrics

Slicers for hospital type, category, state, and city to filter easily
